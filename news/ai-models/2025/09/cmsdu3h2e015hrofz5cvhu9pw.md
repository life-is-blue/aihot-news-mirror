# DeepSeek-V3.1 更新至 Terminus 版本，优化语言一致性与 Agent 能力

DeepSeek-V3.1 已更新至 DeepSeek-V3.1-Terminus 版本，在保持原有能力基础上，缓解了中英文混杂、偶发异常字符等问题，并优化了 Code Agent 与 Search Agent 的表现。官方 App、网页端、小程序与 DeepSeek API 均已同步更新，开源版本已发布至 Hugging Face。
