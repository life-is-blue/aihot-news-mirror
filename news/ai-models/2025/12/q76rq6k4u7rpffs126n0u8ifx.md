# OpenAI 发布 GPT-5.2 前沿模型

OpenAI 发布 GPT-5.2，称其为面向日常专业工作的最先进前沿模型，具备推理、长上下文理解、编码和视觉能力。用户可在 ChatGPT 和 OpenAI API 中使用，以支持更快、更可靠的智能体工作流。
