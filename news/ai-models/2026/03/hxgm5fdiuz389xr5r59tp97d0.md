# Inception Labs 发布扩散模型 Mercury Edit 2，专注代码 next-edit 预测

Inception Labs 发布 Mercury Edit 2，一个专为 next-edit 预测构建的扩散 LLM（dLLM），基于近期编辑和代码库上下文预测下一步修改，并行生成 token 以降低延迟。
