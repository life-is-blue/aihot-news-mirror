# OpenAI 发布 GPT-5.5，宣称其为"新型智能"并实现 API 价格翻倍

OpenAI 正式推出 GPT-5.5，该模型被定义为一种代理模型，能够通过自主切换多种工具来完成复杂任务。公司宣称其代表了一种"新型智能"。与此同时，GPT-5.5 的 API 调用价格将提升至原来的两倍。
