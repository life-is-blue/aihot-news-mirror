# Ring-2.6-1T 正式开源：蚂蚁百灵发布万亿级思考模型

蚂蚁百灵开源万亿级思考模型 Ring-2.6-1T，重点强化 Agent 执行能力，在 PinchBench 和 ClawEval 上达到开源 SOTA。模型支持 high 与 xhigh 两档推理强度，并采用异步 Async RL 架构结合升级版棒冰算法提升训练效率。权重已开源至 Hugging Face 和 ModelScope，Chat 体验现已开放。
