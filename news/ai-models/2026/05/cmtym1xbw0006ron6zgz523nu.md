# Cohere 开源 Command A+：218B 参数 MoE 模型主打企业级智能体能力

Cohere 发布 Command A+ 并以 Apache 2.0 许可开源权重，模型采用 MoE 架构，总参数 218B、激活 25B，支持 128K 输入上下文和 48 种语言。
