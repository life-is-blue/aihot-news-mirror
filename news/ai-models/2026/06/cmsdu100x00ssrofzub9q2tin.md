# Kimi K2.7 Code 高速版上线：输出速度约 5-6 倍，API 定价为普通版 2 倍

Kimi K2.7 Code 高速版已上线，与普通版为同一模型，输出速度约 5-6 倍，常规编程场景下约 180 Token/s，短上下文可达 260 Token/s，API 定价为普通版的 2 倍。
