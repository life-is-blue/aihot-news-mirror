# OpenAI 推出两款新转录模型 API

我们在 API 中引入了两种新的转录模型：

• GPT-Live-Transcribe：专为低延迟实时转录而构建。
• GPT-Transcribe：针对已完成音频文件和批量工作负载的异步转录进行了优化。

两种模型都能更好地理解上下文，并在跨口音和语言的实际音频上提供更准确的转录，包括短句、数字、专业术语以及背景噪音较大的语音。
