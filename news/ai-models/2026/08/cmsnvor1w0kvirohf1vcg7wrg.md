# Microsoft 发布 MAI-Image-2.6，Arena 文生图榜排名第二

Microsoft 发布 MAI-Image-2.6，在 Arena 文生图排行榜上位列第二，超过 Meta、Google 和 xAI 的模型。该模型相较 MAI-Image-2.5 整体提升 +79 Elo，文本渲染单项提升 +91 Elo，各测量类别均有改进；现已可在 Arena 体验，本周后续登陆 MAI Playground，并将逐步推广到 Microsoft Foundry 等产品。
