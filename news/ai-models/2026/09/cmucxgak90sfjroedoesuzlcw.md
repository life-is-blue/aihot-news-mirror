# Anthropic 发布 Claude Opus 5.5，速度提升约 30%、成本低约 40%

Anthropic 推出 Claude 5.5 家族首个模型 Claude Opus 5.5，官方称其在多数任务上达到 Claude Fable 5.1 的水平，运行成本比 Opus 5 低 40%。Claude Devs 补充称其每任务速度快约 30%；在 Claude Code 中，5 小时会话限额今日提升 20%，因 Opus 5.5 定价更低，额度内可用量多 25%，Pro、Max 和 Team 用户还将获得一次可随时使用的额度重置。引用图显示 Opus 5.5 在 Terminal-Bench 4.0 各 effort 档位下得分领先。
