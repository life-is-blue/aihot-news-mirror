# Anthropic 发布 Claude Sonnet 5.5，Claude Code 任务完成量提升约 30%

Anthropic 发布 Claude Sonnet 5.5，是 Claude 5.5 家族的第二个模型。官方称相比 Sonnet 5 运行速度提升超过 30%，多数工作成本最高降低 30%；在 Claude Code 中用户完成的任务量比 Sonnet 5 多约 30%，同样工作所需 token 更少。视频演示中该模型用工具调用完成清理落叶任务，比 Sonnet 5 快 24 秒且少用 6K token。
