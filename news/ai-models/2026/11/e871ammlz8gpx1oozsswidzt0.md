# 可灵AI 发布 Kling Image 4.0 图像生成模型并开放 API 接入

可灵AI 发布全新图像创作模型 Kling Image 4.0，现已全量上线并面向企业客户与开发者开放 API 接入。新模型采用理解生成统一架构，首次支持原生 8K 图像生成，支持单张图最多生成 2000 字文本、最高 15000 tokens 文本输入，一次描述最多生成 10 张组图，并支持电商详情页与网页设计长图。
