# Gradio 3.0 发布：全新前端设计与 Blocks 低阶 API

Hugging Face 发布 Gradio 3.0，对库进行了彻底重构设计。前端改用 Svelte 等现代技术带来更小的载荷和更快的页面加载，组件更新增 Gallery 和 TabbedInterface；新推出的 Gradio Blocks 低阶 API 支持在 Python 中自定义布局、多步骤数据流和组件属性动态控制。
