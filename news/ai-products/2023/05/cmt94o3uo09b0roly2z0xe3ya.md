# LangChain 推出 Plan-and-Execute 智能体执行器

LangChain 发布名为 Plan-and-Execute 的新型智能体执行器，先由 planner 规划步骤，再由执行器逐步完成，与此前基于 ReAct 的 Action Agent 形成对比。该设计将规划与执行分离以提升可靠性，代价是更多 LLM 调用，灵感来自 BabyAGI 和 Plan-and-Solve 论文，首版放在实验模块，提供 Python 和 JS/TS 文档。
