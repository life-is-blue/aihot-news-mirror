# LlamaIndex 发布 LlamaParse 及托管摄取与检索服务

LlamaIndex 推出面向 LLM 与 RAG 应用的托管解析、摄取与检索服务套件 LlamaParse。LlamaParse 专注解析含表格和图表的复杂文档，已进入公开预览，当前聚焦 PDF 并对公开用户设用量上限；托管摄取与检索 API 处于私有预览，支持通过 LlamaHub 接入超过 150 个数据源和 40 多种数据存储方案。
