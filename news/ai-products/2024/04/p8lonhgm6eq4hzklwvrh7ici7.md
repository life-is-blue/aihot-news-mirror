# OpenAI 宣布 GPT-4 API 全面可用并公布旧模型退役计划

OpenAI 宣布 GPT-4 API 全面可用，GPT-3.5 Turbo、DALL·E 和 Whisper API 也同时全面开放。同时发布 Completions API 旧模型的退役计划，这些旧模型将于 2024 年初退役。
