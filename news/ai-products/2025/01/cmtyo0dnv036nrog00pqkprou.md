# Modal Sandboxes 正式可用，为不可信代码提供安全执行环境

Modal 宣布 Sandboxes 正式可用，这是安全运行 LLM、用户或第三方来源不可信代码的隔离执行环境。它提供 exec API，可在运行时用与 Functions 相同的 Image API 动态配置任意语言依赖，支持文件系统快照以持久化和多 Sandbox 扇出，并复用 Functions 基础设施带来快速冷启动、GPU 和全球区域选择。
