# LlamaIndex 推出 LlamaExtract 公测：几步即可从非结构化文档提取结构化数据

LlamaIndex 推出 LlamaExtract，现已通过 LlamaParse 的 web UI 和 Python SDK 开放公测，用户定义 schema 后即可从非结构化文档提取 JSON 格式的结构化数据。工具支持 PDF、扫描件和 100 页以上长文档，基于 LlamaParse 构建，无需手动处理 OCR 和表格解析，输出符合 schema 的类型化数据，并提供免费和付费方案。
