# Mistral 发布 Agents API，内置代码执行、网页搜索与多智能体编排

Mistral AI 发布 Agents API，为智能体用例提供专用框架，与 Chat Completion API 互补。内置连接器覆盖代码执行、网页搜索、图像生成（Black Forest Lab FLUX1.1 [pro] Ultra 驱动）、Document Library 与 MCP 工具，并支持有状态对话、对话分支、流式输出与多智能体 handoff 编排。
