# Cognition 发布 DeepWiki，为任意 GitHub 仓库生成免费 AI 文档

Cognition 推出 DeepWiki，将 Devin Wiki 和 Devin Search 免费公开，把 URL 中的 github.com 换成 deepwiki.com 即可查看任意仓库的 AI 文档。已索引超过 50，000 个热门公开仓库，涵盖 Model Context Protocol、LangChain 等；公开仓库可免费添加，私有仓库需 Devin 账号。
