# Cursor 与 Linear 推出深度集成，可直接在 Linear 中指派任务给 Cursor 智能体

Cursor 与 Linear 推出新集成，用户可直接在 Linear 中将问题指派给 Cursor 智能体，如同指派给队友。智能体能承担编码任务、创建 PR 并在 Linear 中更新进度，降低团队处理低优先级问题的激活成本。该集成利用 Linear 的 SDK 和 GraphQL 类型快速构建，Cursor 产品经理 Rohan Varma 表示新 API 一天内即可上线运行。
