# Mistral 为 Le Chat 推出 20+ MCP 连接器和 Memories 功能

Mistral 为 Le Chat 推出 beta 版 Connectors 目录和 Memories 功能，两者对所有用户免费开放。连接器覆盖 20+ 企业工具，包括 Databricks、Snowflake、GitHub、Notion、Stripe 等，并支持自定义 MCP 连接器；Memories 可跨对话保存上下文，支持随时增删改，还可从 ChatGPT 快速导入。
