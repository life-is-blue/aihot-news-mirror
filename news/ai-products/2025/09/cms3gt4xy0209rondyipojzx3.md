# Claude Platform 发布 Code Execution Tool v2 公测版，支持 Bash 命令与文件操作

Claude Platform 推出 Code Execution Tool v2 公测版，取代原先仅支持 Python 的工具，新增 Bash 命令执行和直接文件操作能力，包括用其他语言编写代码。
