# Claude Platform 推出结构化输出公测，支持 Claude Sonnet 4.5 和 Opus 4.1

Claude Platform 上线结构化输出公测，可为 Claude 的响应提供有保证的 schema 一致性。开发者可通过 JSON 输出获取结构化数据，或使用严格工具调用进行验证。该功能适用于 Claude Sonnet 4.5 和 Claude Opus 4.1，需在请求中设置 beta 头 `structured-outputs-2025-11-13`。
