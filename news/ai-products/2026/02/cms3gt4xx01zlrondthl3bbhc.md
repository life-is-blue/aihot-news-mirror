# Claude API 推出自动缓存功能，并退役 Sonnet 3.7 与 Haiku 3.5 模型

Claude Messages API 新增自动缓存功能，只需在请求体中添加 `cache_control` 字段，系统即可自动缓存最后一个可缓存块，无需手动管理断点，并可与现有块级缓存配合使用。
