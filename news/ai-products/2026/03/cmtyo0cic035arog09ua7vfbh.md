# LlamaIndex 开源 LiteParse：面向 AI Agent 的本地文档解析工具

LlamaIndex 开源 LiteParse，一个完全本地运行的 CLI 和 TS 原生库，可从 PDF、Office 文档和图片中提取布局感知文本，无需 Python 依赖，内置 Tesseract.js OCR 并支持外接 PaddleOCR、EasyOCR 等 OCR 服务。
