# Manus 发布桌面应用"我的电脑"，让 Agent 直接操作本地机器

Manus 发布 Manus 2.0 桌面应用的核心功能"我的电脑"，将 Agent 从云端扩展到用户本地电脑，通过在本地终端执行命令行指令来读取、编辑文件和控制应用，现已面向所有 macOS 和 Windows 用户开放。
