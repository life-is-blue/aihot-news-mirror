# Claude 推出 Managed Agents 公开测试版与 ant CLI 命令行客户端

Claude 发布 Managed Agents 公开测试版，这是一个完全托管的智能体框架，支持通过 API 创建智能体、配置容器并运行会话，具备安全沙箱、内置工具和 SSE 流式传输。同时推出 ant CLI 命令行客户端，可加速与 Claude API 的交互，原生集成 Claude Code，并支持以 YAML 文件管理 API 资源版本。
