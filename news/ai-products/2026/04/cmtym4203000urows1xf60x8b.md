# Factory 发布桌面应用，为 Droids 提供原生界面并支持本地模型运行

Factory 发布桌面应用，为 Droids 提供原生界面，今日上线 macOS 和 Windows。主要功能包括多智能体会话、持久化 Droid Computers（含 Cloud Computers 与 BYO Machine）、计算机操作能力、VS Code 集成、动态可视化、移动端支持，以及通过 Ollama、vLLM 等端点在本地 GPU 上运行模型、数据不出内网。
