# Agents SDK TypeScript版更新发布

更新后的 Agents SDK 现已提供 TypeScript 版本，支持沙盒代理并内置开源测试框架。

【引用 @OpenAIDevs】：构建可长期运行的代理，获得更多对代理执行的控制权。

Agents SDK 的新功能：
• 在受控沙盒中运行代理
• 检查并自定义开源测试框架
• 控制记忆创建时机及存储位置
