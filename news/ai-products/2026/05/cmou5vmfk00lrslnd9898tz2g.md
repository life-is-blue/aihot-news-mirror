# Perplexity Agent API 新增金融搜索功能

Perplexity Agent API 现已提供金融搜索功能。

开发者只需一次工具调用，即可为需要当前可验证金融答案的智能体获取授权金融数据集、实时市场数据和附引用的网络资源。
