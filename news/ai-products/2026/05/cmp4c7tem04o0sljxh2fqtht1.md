# Claude付费计划将提供月度编程使用额度

自6月15日起，付费Claude计划可申领专用的月度编程使用额度。

该额度涵盖以下用途：
- Claude Agent SDK
- claude -p
- Claude Code GitHub Actions
- 基于Agent SDK构建的第三方应用
