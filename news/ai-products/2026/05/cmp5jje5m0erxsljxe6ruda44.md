# Kimi推出网页桥接扩展 支持多平台交互

认识Kimi网页桥接--Kimi的浏览器扩展。

现在智能体可以像人类一样与网站互动：搜索、滚动、点击、输入并完成任务。

支持Kimi Code CLI、Claude Code、Cursor、Codex、Hermes等平台。

现已在http://kimi.com/features/webbridge和Chrome应用商店上线。
