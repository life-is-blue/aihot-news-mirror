# Kimi发布支持多款AI编程助手的浏览器扩展

Kimi发布了Kimi Web Bridge，这是一款可与多种代理协同工作的新浏览器扩展，包括Claude Code、Hermes、Codex、Kimi Code CLI等。

一浏览器通用于所有 👀

试用地址：http://kimi.com/features/webbridge 及Chrome网上应用店。
