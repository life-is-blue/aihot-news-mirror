# OpenRouter支持模型生成文件补丁

OpenRouter 现已支持 "apply_patch"，这是一个服务器工具，允许任何模型通过 Responses API 使用 V4A diffs 提出文件编辑建议。

模型生成一个补丁（创建、更新或删除文件）。OpenRouter 在服务器端验证 diff 语法。
