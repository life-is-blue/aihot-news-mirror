# Codex Windows端重大升级，支持计算机操作与移动端协同

Codex 用户在 Windows 上迎来重大升级：

现在计算机操作功能已在 Windows 上可用，Codex 可以在你的 Windows 电脑上执行操作。

同时，ChatGPT 移动应用中的 Codex 也支持 Windows，让你可以随时随地启动、审查和引导任务，而工作则在你的 Windows 机器上继续进行。

这是一次早期体验，但我们正在努力提供更多方式，让你无论身在何处都能保持工作推进。
