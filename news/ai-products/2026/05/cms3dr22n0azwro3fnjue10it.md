# Linear 发布 Diffs，主打快速聚焦的代码评审

Linear 推出代码评审产品 Diffs，今日起向所有 Linear 套餐开放，设置步骤见 Changelog。评审在 Linear 内打开近乎即时，并附带产生变更的 issue、项目和客户信号；Guided reviews 会按工作思路把大 diff 分成章节，先展示变更核心再讲后续影响，结构性 diff 高亮会剥离与程序行为无关的格式改动，官方称 2,000 行的 PR 可在一次阅读中看清。
