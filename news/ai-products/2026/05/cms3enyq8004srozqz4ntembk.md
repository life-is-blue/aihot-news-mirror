# Claude Platform on AWS 新增 Managed Agents webhooks、多智能体编排与自托管沙箱

Claude Platform on AWS 现已支持 Managed Agents webhooks、多智能体编排和自托管沙箱。新增了 IAM 操作及 `AnthropicSelfHostedEnvironmentAccess` 托管策略，用于在 AWS 上管理 Claude 智能体的触发、协作与安全执行环境。
