# Claude Platform 正式推出 Workload Identity Federation

Claude Platform 的 Workload Identity Federation 现已正式可用。该功能允许用户使用来自 AWS IAM、Google Cloud、GitHub Actions 等身份提供商的短期 OIDC 令牌认证 Claude API，替代长期静态 API 密钥。
