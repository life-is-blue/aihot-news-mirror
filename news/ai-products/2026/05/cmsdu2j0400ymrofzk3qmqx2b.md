# MiMo-V2.5 系列 API 永久降价，最高降幅 99%

小米 MiMo-V2.5 系列 API 自北京时间 5 月 27 日 0 点起永久降价，相比原始定价最高降幅达 99%，且不再区分上下文窗口长度。Token Plan 计费体系同步优化，用量提升至原来的 5-8 倍，现有有效用户额度全量重置。降价背后是基于 SGLang HiCache 的 SWA 支持，将 KV Cache 数据搬运量降至优化前近 1/7，可缓存 token 数量提升近 5 倍。
