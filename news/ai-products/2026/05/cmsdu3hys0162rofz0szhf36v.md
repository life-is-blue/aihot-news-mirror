# MiniMax 升级 Agent 为 Mavis，推出 Agent Teams 多智能体协作

MiniMax 将升级后的 Agent 命名为 Mavis，并上线 Agent Teams，支持桌面端多个 Agent 并行协作，以解决单 Agent 在复杂任务中易中途停止、长任务性能下降、响应慢及角色分工不清等痛点。
