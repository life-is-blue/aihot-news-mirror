# LlamaIndex 发布 LiteParse v2.0：Rust 重写，支持 Rust、Python、Node、WASM 与 edge 运行时

LlamaIndex 发布 LiteParse v2.0，将这个不依赖 LLM 的 PDF 与办公文档解析工具用 Rust 重写，提供 Rust、Python、Node 和 WASM 四种包，可在浏览器和 edge 运行时本地运行。
