# LlamaIndex 发布 LiteParse Server 可自托管文档解析服务

LlamaIndex 发布 liteparse-server，将 LiteParse 封装为可自托管的 HTTP 文档解析服务，支持 PDF、Word、PowerPoint、表格和图片，输出带 bounding box 的空间布局文本。
