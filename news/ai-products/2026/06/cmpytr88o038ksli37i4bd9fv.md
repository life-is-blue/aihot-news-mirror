# Grok 登陆 Cloudflare AI Gateway

xAI 与 Cloudflare 合作，将 Grok 的 LLM、音频、图像和视频模型接入 Cloudflare AI Gateway，用户可直接通过 Cloudflare 计费，无需额外认证或 API 密钥。Elon Musk 发推称 "Grok on Cloudflare"。
