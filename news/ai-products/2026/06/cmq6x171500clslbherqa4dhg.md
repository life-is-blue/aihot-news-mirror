# Responses API 网页搜索新增图片结果

你的应用现在可以搜索网页上的图片。

Responses API 中的网页搜索现在除了文本结果外，还支持图片结果，因此你可以构建能展示商品、地点、视觉参考和来源链接以激发灵感的应用。
