# Linear Agent 新增编码会话、自动分类与代码审查功能

Linear Agent 推出编码会话、自动分类和 Diffs 代码审查，使智能体可直接从 issue 进入代码实现、自动调查并修复问题，并在 Linear 内完成代码审查与合并。编码会话基于 Claude Code 或 Codex 在云端运行，结果归组织所有。过去一个月，Linear Agent 已合并近 700 个 PR。
