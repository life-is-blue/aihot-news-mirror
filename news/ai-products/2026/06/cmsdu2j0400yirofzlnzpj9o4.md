# MiMo Code 发布并开源：模型 Agent 协同优化，迈向自进化时代

小米发布并开源终端 AI 编程助手 MiMo Code V0.1.0，基于 OpenCode 二次开发，采用 MIT 协议。其内置限时免费的 MiMo-V2.5 多模态模型，支持接入 DeepSeek、Kimi、GLM 等，并配备持久记忆系统与独创 Compose 模式。
