# LlamaIndex 发布 Retrieval Harness，扩展 LlamaParse Index 检索能力

LlamaIndex 宣布扩展 LlamaParse Index，新增 Retrieval Harness，为 Agent 提供文件系统式文档遍历工具，包括 Hybrid Retrieve、List Files、File Grep 和 File Read。
