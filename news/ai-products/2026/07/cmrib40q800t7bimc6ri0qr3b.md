# OpenAI 为 50 万 ChatGPT Work 和 Codex 用户增加"banked reset"功能

OpenAI 为 50 万 ChatGPT Work 和 Codex 用户增加了"banked reset"功能，现已支持网页和移动端使用，此前仅限桌面端。期间曾出现 2 小时窗口内不到 10% 用户重置未生效的问题，OpenAI 为所有在该窗口内点击重置按钮的用户补发了重置额度。明天将庆祝 700 万活跃用户里程碑，并向所有 ChatGPT Work 和 Codex 用户发放首次重置额度，同时发布桌面端多项更新。
