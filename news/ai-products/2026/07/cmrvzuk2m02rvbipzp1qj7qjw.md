# 蚂蚁 inclusionAI 开源沙箱生命周期服务 sandboxd

蚂蚁集团 inclusionAI 在 GitHub 开源 sandboxd，这是 AKernel 使用的 Linux 沙箱生命周期服务，通过 gRPC API 管理沙箱资源，当前基于 gVisor 运行沙箱，并计划近期开源 Kata Containers 支持。
