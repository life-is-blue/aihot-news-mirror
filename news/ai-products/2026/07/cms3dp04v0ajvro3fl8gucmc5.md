# Anthropic 推出 Claude Managed Agents 公测版及 ant CLI 工具

Anthropic 在 Claude Platform 发布说明中宣布推出两项新功能：一是 Claude Managed Agents 进入公开测试阶段，这是一个全托管的 Agent 运行环境，提供安全沙箱、内置工具和服务器发送事件流式传输，支持通过 API 创建代理和配置容器；二是发布了 ant CLI，这是 Claude API 的命令行客户端，支持与 Claude Code 原生集成及 YAML 格式的资源版本管理。使用 Managed Agents 需添加特定 Beta Header。
