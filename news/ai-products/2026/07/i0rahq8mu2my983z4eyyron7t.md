# Codex Code Review 支持在 AGENTS.md 中编写自定义仓库审查规则

OpenAI 为 Codex Code Review 推出自定义仓库规则功能，可在 AGENTS.md 中写明审查指导，Codex 在审查时应用相关规则并在 finding 中引用依据。官方测试显示规则引导下可找回 98% 的应报告问题，基线为 58.3%；文中还给出规则应小范围划分、写明不变量和安全路径、机械检查留给 CI 等撰写建议。
