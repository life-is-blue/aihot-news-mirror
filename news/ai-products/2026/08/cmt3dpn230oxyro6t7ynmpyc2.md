# Claude Platform 发布 Python SDK v1.0，迁移至 httpx2

Anthropic 发布 Claude Python SDK v1.0，HTTP 层从 httpx 迁移至 API 兼容的 httpx2，并移除 Text Completions API 等长期弃用功能。
