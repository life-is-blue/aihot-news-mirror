# Gemini API 为 Gemini 3.7 Flash 等模型推出 Agentic 视频理解

Gemini API 为 Gemini 3.7 Flash、3.6 Flash 和 3.5 Flash-Lite 推出 Agentic 视频理解，覆盖 Interactions 和 GenerateContent 两个 API。模型可动态导航视频时间线，按需请求转写、帧或音频轨，长视频内容相比静态处理最多节省 88% 的 token。
