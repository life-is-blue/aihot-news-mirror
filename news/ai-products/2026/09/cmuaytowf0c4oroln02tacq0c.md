# Kimi 发布 Kimi Code Desktop 1.0，macOS 与 Windows 版同步上线

Kimi（月之暗面）发布 Kimi Code Desktop 1.0，作为 Kimi Code 官方桌面客户端，macOS（Apple 与 Intel 芯片）和 Windows 版同步上线，下载地址为 kimi.com/code。
