# Google Cloud API Gateway 推出 MCP 支持，可将现有 REST API 直接暴露为智能体工具

Google Cloud API Gateway 在 Public Preview 中可充当远程 MCP 服务器，无需单独搭建 MCP 服务器，即可把已有 REST API 暴露为智能体可调用的工具。
