# Microsoft 发布新版 Copilot：新增 Home、Code 与 Autopilot 三大能力

Microsoft 官方宣布重构 Microsoft Copilot，推出三项新能力：Home 作为统一起点整合 Chat 与 Cowork 并内置 Office，Code 让普通用户用自然语言构建可安全运行的小型方案（与 GitHub Copilot 同源技术），Autopilot（原 Scout）成为持续主动工作的数字 teammate。
