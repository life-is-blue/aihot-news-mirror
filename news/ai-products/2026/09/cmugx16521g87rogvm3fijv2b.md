# Microsoft 发布新 Copilot：新增 Home、Code 与 Autopilot

Microsoft 官宣新版 Copilot，推出三大新能力：Home 整合 Chat 与 Cowork 并内置 Word、Excel、PowerPoint；Code 让非开发者用自然语言构建应用，与 GitHub Copilot 同源技术并在沙箱中运行；Autopilot（原 Scout）是可主动持续工作的智能体。
