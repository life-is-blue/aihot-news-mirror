# Claude Opus 5.5 成为 Claude Code 和 Claude 应用的默认模型

Anthropic 的 Claude Opus 5.5 现已成为 Claude Code 和 Claude 应用（含 Cowork）在 Pro、Max 和 Team 套餐中的默认模型。默认使用 effort medium，智能水平与 Fable 5.1 相当但更快；相比 Opus 5，速率限制可多用 25%，运行成本低 40%。作者称其沟通清晰、写作贴合个人风格。
