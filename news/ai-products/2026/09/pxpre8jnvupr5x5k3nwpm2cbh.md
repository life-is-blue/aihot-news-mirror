# Ollama 支持基于 Jev API 的决策模型，新增 nimble 等三款模型

Ollama 0.35 通过新 /v1/systemone 端点支持基于 TypeSafe Jev API 的决策模型，可在本地一次请求回答多个命名问题，适合工单分诊、模型路由和内容审核等快速决策任务。
