# GPT-6 与 Intelligent UI 向全部 ChatGPT 用户推出

OpenAI 宣布 GPT-6 与 Intelligent UI 正在 ChatGPT 中向所有用户推出。Intelligent UI 提供快速的交互式回答，让日常问题更直观、复杂主题更易理解，并可即时提供面向任务的交互式工具。OpenAI Codex 产品设计成员 Ed Bayes 转发该消息并称赞团队工作。
