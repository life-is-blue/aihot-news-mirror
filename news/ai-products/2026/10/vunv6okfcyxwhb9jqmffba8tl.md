# DeepSeek 开放 Search & Fetch API，每千次调用 $0.75

DeepSeek 宣布 Search & Fetch API 现已向所有人开放，由其自研搜索引擎驱动，每日在全球处理数亿次请求。每个 endpoint 定价 $0.75 per 1,000 calls；在 DeepSeek Harness、Claude Code 和 Codex 中通过服务端工具调用目前对 DeepSeek API 用户免费，2026-10-31 16:00 UTC 起开始计费。文档见 https://api-docs.deepseek.com/guides/search
