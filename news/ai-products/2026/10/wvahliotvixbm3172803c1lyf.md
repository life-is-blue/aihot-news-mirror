# Cursor 正式推出 Agent SDK，可用代码文件夹定义并部署智能体

Cursor 正式推出 Agent SDK，支持以代码文件夹形式定义智能体，用评估测试，并部署到 Cursor 或自有基础设施。运行 npx @cursor/agent-sdk init 即可初始化，agent-sdk deploy 会构建智能体并分配 URL；提供安全审查、PR 自动修复、Linear / Jira 分诊等模板。
