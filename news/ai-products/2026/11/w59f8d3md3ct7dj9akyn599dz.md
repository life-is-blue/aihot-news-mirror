# Amp 发布 spaces：由单个 Agent 自动生成和协调多线程的协作空间

Amp 今日推出 spaces，一种与 Agent 和团队协作的新方式。每个 space 是与单个 Agent 的对话，由它负责为用户生成和协调其他 Agent 线程，无需自己创建和组织线程。
