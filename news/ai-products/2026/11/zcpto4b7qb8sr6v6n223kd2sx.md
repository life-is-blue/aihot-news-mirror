# Claude 推出 Install as app：artifacts 可安装为 Mac 和 Windows 桌面应用

Anthropic 在 Mac 和 Windows 版 Claude 中以 beta 形式推出 Install as app，artifacts 可创建、运行并分享为独立桌面应用，拥有自己的图标和窗口，底层 artifact 更新时应用自动同步。
