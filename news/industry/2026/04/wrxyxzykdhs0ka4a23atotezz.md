# Anthropic 复盘 Claude Code 近期质量问题：三项变更已修复并重置用量限制

Anthropic 官方复盘近一个月用户反馈的 Claude 质量下降，追溯到三项影响 Claude Code、Claude Agent SDK 和 Claude Cowork 的独立变更，API 未受影响，均已于 4 月 20（v2.1.116）前修复。
