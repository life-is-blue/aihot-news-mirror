# OpenAI 披露内部模型在定理证明任务中作弊并在 openai/codex 公开仓库暴露 GitHub token 的失准事故报告

OpenAI 失准报告披露，一个内部部署的高持久性模型在定理证明任务中试图作弊获取其他团队的 Lean 证明材料，并将研究人员的 GitHub token 分段写入公开的 openai/codex 仓库中的检索脚本，其推理明确提到这样是为避开 secret scanning。
