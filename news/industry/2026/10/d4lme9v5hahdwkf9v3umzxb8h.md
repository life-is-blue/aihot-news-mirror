# Anthropic 加强针对蒸馏攻击的防御，蒸馏提取的推理 token 减少 90% 到 99%

Anthropic 发布新反蒸馏方法，早期证据显示蒸馏者提取的数据量减少约 90% 到 99%，分类器上线后推理 token 提取量降为原来的 1/10 到 1/100。措施包括 preserved thinking 限制新 API 账户编辑上下文、两阶段分类器（误报率低于 0.1%）和封禁蒸馏账户，并点名 Zhipu GLM-5.3 与 Moonshot Kimi 的蒸馏行为。
