# LangChain 撰文分析 OpenAI 押注 GPTs 与 Assistants API 背后的认知架构

LangChain 撰文认为 OpenAI 开发者日发布的 GPTs 和 Assistants API 代表对封闭式 agent 认知架构的押注，即由 LLM 全权决定状态转移。文章指出当前真正可靠的应用多采用复杂链或状态机架构，并强调推送而非拉取上下文能带来更高可控性，同时提出开源认知架构与闭源之争将比模型之争更值得关注。
