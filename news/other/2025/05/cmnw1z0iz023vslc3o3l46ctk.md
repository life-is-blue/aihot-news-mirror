# 将Agent封装为MCP服务器示例

MCP Agent Server示例展示了将Agent工作流封装为MCP服务器的"Agent即服务"架构。提供asyncio（轻量级内存执行，适合开发测试）和Temporal（生产级持久化、支持暂停恢复）两种实现。通过装饰器暴露Agent能力，支持多Agent互操作，可与Claude Desktop等任意MCP客户端集成，实现复杂工作流的标准化封装与跨平台复用。
