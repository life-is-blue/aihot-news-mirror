# Claude Code 发布网页版

Anthropic 推出网页版 Claude Code，以研究预览形式向 Pro、Max 及企业用户开放。用户可直接在浏览器中分配编码任务，无需本地终端，支持并行处理多个 GitHub 仓库的开发工作，并自动创建 PR 和变更摘要。该服务基于云端隔离沙盒运行，具备网络和文件系统限制，同时登陆 iOS 应用支持移动编码。云会话与现有 Claude Code 使用共享速率限制。
