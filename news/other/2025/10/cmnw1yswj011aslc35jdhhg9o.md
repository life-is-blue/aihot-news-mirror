# Gemini 与 Google Cloud 推出组织上下文数据及 Agent 系统新功能

Google 为 Gemini 和 Google Cloud 推出一系列新功能，支持基于组织上下文数据构建 Agent 系统，实现企业数据信息提取与任务自动化，例如根据历史会议记录自动整理项目待办事项。
