# Claude 现已支持控制电脑完成任务

Claude 推出电脑控制功能，可自动打开应用、操作浏览器、填写表格等，替代用户完成桌面操作。该功能目前处于研究预览阶段，已在 Claude Cowork 和 Claude Code 上线，仅支持 macOS 系统。
