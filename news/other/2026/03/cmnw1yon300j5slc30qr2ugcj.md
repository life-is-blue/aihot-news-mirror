# 🤯 现可通过手机在笔记本电脑上启动 Claude Code 会话

Claude Code 推出远程控制功能，运行 `claude remote-control` 后可直接在手机 App 上启动电脑端新会话。该功能已向 Max、Team 及 Enterprise 用户（v2.1.74+）开放，目前需先在手机配置 GitHub，启动速度优化中。
