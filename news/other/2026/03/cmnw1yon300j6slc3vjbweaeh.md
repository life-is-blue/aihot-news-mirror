# 🎁 周五快乐 -- Opus 4.6 1M 现已成为 Max、Team 及企业版 Claude Code 用户的默认模型

Claude Code 向 Max、Team 和企业版订阅用户默认启用 Opus 4.6 1M 模型，支持 100 万 token 上下文窗口。Pro 与 Sonnet 用户可通过 /extra-usage 指令手动开启该功能。
