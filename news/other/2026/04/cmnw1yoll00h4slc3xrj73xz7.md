# Claude Cowork 和 Claude Code Desktop 的 Computer use 功能现已支持 Windows

Claude Cowork 与 Claude Code Desktop 的 Computer use 功能正式登陆 Windows，结束 macOS 独占。该功能支持 Claude 直接控制电脑打开应用、浏览网页、填写表格等，完成各类桌面任务。
