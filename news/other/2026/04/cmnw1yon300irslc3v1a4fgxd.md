# Claude 订阅权益调整：明天起不再覆盖第三方工具使用

明天 12pm PT 起，Claude 订阅不再涵盖 OpenClaw 等第三方工具使用。用户可通过折扣价购买额外使用包，或使用 Claude API 密钥继续访问这些工具。
