# Claude Code 终端版推出 NO_FLICKER 模式

Claude Code 终端版新增 NO_FLICKER 模式，采用实验性渲染器解决闪烁问题，支持鼠标事件，设置环境变量 CLAUDE_CODE_NO_FLICKER=1 即可启用。
