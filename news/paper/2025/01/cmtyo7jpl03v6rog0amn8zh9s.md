# Aim Labs 披露 Cursor IDE 的 CurXecute 漏洞，可经 MCP 提示词注入实现 RCE（CVE-2025-54135）

Aim Labs（Cato）披露 Cursor IDE 的高危漏洞 CurXecute（CVE-2025-54135，评分 8.6），外部托管的一条提示词注入可静默改写 ~/.cursor/mcp. 并以用户权限执行任意命令，实现 RCE。
