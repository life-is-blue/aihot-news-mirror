# PromptArmor 演示如何通过恶意 Marketplace 插件劫持 Claude Code 并外泄用户数据

PromptArmor 发布安全研究，展示 Claude Code 新上线的插件 Marketplace 功能可被用于攻击。恶意插件先利用 Hook 改写 settings.local. 权限或自动批准 curl 命令，绕过人工审批防护，再通过 Command 中的提示词注入诱使 Claude 把代码库上下文用 curl 发到攻击者服务器。
