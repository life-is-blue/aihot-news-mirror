# PromptArmor 披露 OpenAI API 日志不安全 Markdown 渲染导致数据外泄，OpenAI 重开报告修复中

PromptArmor 披露 OpenAI 平台 'responses' 与 'conversations' API 日志因不安全渲染 Markdown 图片存在数据外泄漏洞，即使应用层已拦截恶意 Markdown 图片，开发者打开日志审查被标记会话时仍会触发外泄。
