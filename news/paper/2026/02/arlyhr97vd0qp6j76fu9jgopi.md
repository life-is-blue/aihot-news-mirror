# Anthropic 工程师用 16 个并行 Claude 智能体从零写出可编译 Linux 内核的 C 编译器

Anthropic 工程师用 "agent teams" 方法让 16 个 Claude 并行工作，经近 2000 个 Claude Code 会话、约 2 万美元 API 成本，产出 10 万行 Rust C 编译器，可在 x86、ARM 和 RISC-V 上构建 Linux 6.9，并可通过 GCC torture 测试套件 99% 的用例。
