# AISI 实验显示沙箱中的 OpenClaw Agent 能推断出评估环境信息

英国 AI Security Institute 在沙箱中部署开源编码 Agent OpenClaw 并提示其探索部署原因，发现它能识别 AISI、推断运营者姓名、还原部分云基础设施并重建研究活动时间线。
