# MIT 与 Microsoft 论文：GitHub Copilot 使初级软件工程师招聘下降约 40%

MIT 和 Microsoft 的新论文《AI-Assisted Programming and Labor Demand》利用 5,414 家跨国公司（覆盖 38% 美国程序员）的 GitHub 合同审查时点构造自然实验，估计 Copilot 采用对劳动力需求的影响。
