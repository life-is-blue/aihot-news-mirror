# LangChain 官方教程：AI Agent 提速的实用方法

LangChain 博客介绍开发者加速 AI Agent 的常见做法：先用 LangSmith 诊断延迟来源，再通过流式输出和后台运行降低用户感知延迟。其他要点包括减少 LLM 调用次数（如用 LangGraph 精确控制智能体通信）、换更快模型、削减输入上下文以及并行执行 LLM 调用。
