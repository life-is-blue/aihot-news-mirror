# Hugging Face Hub 从 Git LFS 迁移至 Xet 并将向所有用户开放

Hugging Face 宣布 Hub 存储后端从 Git LFS 迁移到 Xet，半年内 50 万个仓库、20PB 数据完成迁移，用户超 100 万，5 月起对新用户默认启用。
