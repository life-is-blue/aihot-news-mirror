# Hugging Face 教你用 Gradio MCP Servers 给 LLM 增加新能力

Hugging Face 发文介绍如何通过 Gradio MCP Servers 为 LLM 添加新能力。Gradio 自 5.28.0 版本起支持 MCP 协议，使 Hugging Face Spaces 上数千个应用可作为 MCP 服务器使用，文章以 Flux.1 Kontext[dev] 图像编辑为例，演示了在设置中添加 Spaces Tools 并接入 Cursor 的完整步骤。
