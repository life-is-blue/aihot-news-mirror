# LangChain 重建 Chat LangChain：放弃向量嵌入，改用直接 API 访问与 Deep Agent 子图

LangChain 重建了 chat.langchain.com，弃用分块加向量数据库的检索方案，改为让智能体通过 Mintlify API、知识库标题扫描和 ripgrep 代码搜索直接访问文档、知识库和代码库的原始结构。
