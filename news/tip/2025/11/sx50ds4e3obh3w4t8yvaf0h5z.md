# Anthropic 讲解用代码执行提升 MCP 智能体的上下文效率

Anthropic 发文讲解如何让智能体通过代码执行方式与 MCP 服务器交互，以提升上下文效率。将 MCP 工具呈现为代码 API 后，智能体按需读取工具定义、在执行环境中过滤中间结果，token 用量从 150,000 降至 2,000，节省 98.7%。文章还介绍了渐进式披露、PII 令牌化隐私保护、状态持久化与 Skills 等收益，并提示需权衡沙箱等执行环境带来的运维成本。
