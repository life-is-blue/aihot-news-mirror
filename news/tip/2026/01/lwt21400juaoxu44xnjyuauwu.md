# LlamaIndex 撰文分析文件接口正成为 Agent 读取和交互上下文的核心方式

LlamaIndex 发文指出，Agent 正越来越多地通过文件和文件系统来读取非结构化上下文，并归纳出三种主要用法：用文件存储和检索长程对话历史、用文件搜索替代朴素 RAG 来获取海量外部上下文、用 Skills 类文件教会 Agent 做事从而绕过 MCP。
