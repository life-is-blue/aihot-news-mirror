# Skyscanner 通过 JetBrains MCP 增强 Codex CLI 的开发实践

Skyscanner 工程师分享了在日常工作流中把 OpenAI Codex CLI 通过 JetBrains MCP server 接入 IDE 的实践。Codex 可调用 get_file_problems 检查编译错误、执行预定义的测试、lint 和格式化运行配置，例如在 Databricks Java SDK 用例中立即发现 NotFound 异常构造函数不匹配的问题。
