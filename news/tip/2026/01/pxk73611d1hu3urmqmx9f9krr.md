# OpenAI 开发者博客讲解如何用 Evals 系统化测试 Codex Agent 技能

OpenAI 开发者博客发布教程，讲解如何像测试 LLM 应用一样，用 evals 系统化评估 Codex 的 Agent 技能。核心流程为定义可度量的成功标准、用 $skill-creator 创建技能、以 codex exec -- 捕获 JSONL 轨迹做确定性检查，再用 --output-schema 输出符合评分规则的 JSON 做风格等定性评估。
