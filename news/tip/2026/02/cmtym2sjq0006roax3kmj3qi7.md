# Answer.AI 揭示未授权工具调用问题：Claude 等模型可调用未授予的工具且 API 不拦截

Answer.AI 的 Piotr Czapla 发现 Claude 4.5 在 solveit 对话中幻觉出一个未授予的工具 add_msg 并成功执行，API 未拦截，且在 Gemini 和 Grok 上也复现了类似行为。
