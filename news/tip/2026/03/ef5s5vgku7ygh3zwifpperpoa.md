# Anthropic 发布 Claude Code auto mode，用模型分类器替代人工审批

Anthropic 推出 Claude Code 的 auto mode，将权限审批委托给基于 Sonnet 4.6 的转录分类器，配合服务端提示词注入探针构成两层防御，用于替代 --dangerously-skip-permissions。
