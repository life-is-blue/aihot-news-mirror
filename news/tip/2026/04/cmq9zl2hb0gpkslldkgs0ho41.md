# 使用Agent SDK搭建自定义编码智能体

OpenRouter Agent SDK 提供 create-agent-tui 和 create-headless-agent 两种技能，可在几分钟内脚手架搭建个性化编码智能体。前者附带终端 UI，后者为无头模式，适用于脚本与管道自动化场景。
