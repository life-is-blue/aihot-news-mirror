# TensorZero：别只比每百万 token 单价，LLM API 的隐性成本差距可达 5.3 倍

TensorZero 测量发现同一输入在不同厂商的 token 计数相差可达 2.65 倍，按每百万 token 单价比较 LLM API 成本会产生误导。
