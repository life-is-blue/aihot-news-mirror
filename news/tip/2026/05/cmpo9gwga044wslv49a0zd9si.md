# Codex 支持实时会议转录与问答

OpenAI Codex 新增了"Meeting Recorder"技能。该技能可使用 GPT Realtime Whisper 端点实时转录会议并显示文本。用户可在转录过程中随时向 Codex 提问。会议结束后，会提供完整的转录内容及格式化版本。此功能基于实时 API，费用为 $0.017/分钟。相关代码与说明可在 GitHub 链接中查看。
