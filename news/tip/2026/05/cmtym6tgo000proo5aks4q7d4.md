# PromptArmor 解析 LLM 沙箱域名白名单的常见外泄风险

PromptArmor 分析 Agent 沙箱域名白名单的配置与风险，指出 npmjs.com、github.com、docs.google.com 和 *.amazonaws.com 等常用白名单域名都可能被提示注入用作数据外泄通道，例如通过 Google Forms 预填提交链接或攻击者注册的匹配通配符的子域名。
