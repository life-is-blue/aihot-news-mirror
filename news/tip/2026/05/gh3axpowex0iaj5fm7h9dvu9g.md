# Claude Code 团队成员分享：为什么用 HTML 替代 Markdown 作为 Agent 输出格式

Anthropic 工程师 Thariq Shihipar 撰文介绍他为何在 Claude Code 中改用 HTML 而非 Markdown 作为输出格式，理由包括信息密度更高、长文档更易读、便于分享链接、可加入滑块等双向交互，且 Claude Code 能结合文件系统、MCP、浏览器和 git 历史摄入更多上下文。
