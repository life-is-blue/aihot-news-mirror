# Anthropic Claude Code 团队复盘：如何构建和使用 Skills

Anthropic Claude Code 团队总结内部数百个 skills 的使用经验，将 skills 归为九类（库与 API 参考、产品验证、数据获取与分析、业务自动化、脚手架、代码质量、CI/CD、Runbook、基础设施运维），其中验证类 skills 对输出质量提升最明显。
