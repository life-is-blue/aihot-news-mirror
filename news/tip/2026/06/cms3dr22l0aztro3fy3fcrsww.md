# Linear Agent 自动修复 Bug：从怀疑到协作的工程实践

Linear 工程师通过 Linear Agent 自动化修复两类 Bug：死特性标记和失败后台任务。死特性标记修复成功率接近 100%，失败后台任务修复成功率约三分之一。Agent 在无法修复时仍会完成初步调查，并通过"门控"机制要求其先证明理解问题再尝试修复，以节省 token 和无效 PR。
