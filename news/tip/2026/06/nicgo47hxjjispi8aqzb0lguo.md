# OpenAI 讲解如何用手机远程掌控 Codex 编码工作

OpenAI 开发者博客发布长文，讲解如何在 ChatGPT 移动端通过 Codex Remote 启动、引导、审查和管理运行在开发机上的编码任务。文章提出手机是控制平面而非小型终端，介绍了 Queue 与 Steer 两种跟进方式的区别、/side 侧聊、/goal 持久目标、内联代码评论审查、权限审批和 /compact 等上下文管理命令，并给出发布负责人、移动端审查者等五种实用工作流。
