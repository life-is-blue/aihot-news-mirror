# AWS 通往万亿美元营收之路

AWS 本季度年化营收达 1690 亿美元，同比增长 36.7%，为 18 个季度最快增速，且连续第五个季度加速。Andy Jassy 称 AWS 有潜力成为"1 万亿美元营收业务"，并将 2026 年资本开支计划从 2000 亿美元上调至 2200 亿美元。但 AWS 积压订单仅 4960 亿美元，落后于微软的 6780 亿美元，且自由现金流已转为负 76 亿美元。
