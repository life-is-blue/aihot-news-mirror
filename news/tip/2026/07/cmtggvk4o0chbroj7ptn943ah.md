# AI Harness 对性能的影响超过模型本身：GPT-5.5 与 Opus 4.7 在第三方工具中得分更高

Endor Labs 测试显示，同一模型在不同 harness 中性能差异巨大：GPT-5.5 在 Cursor 中功能正确率 87.2%，远超其在 Codex 原生环境中的 61.5%；Opus 4.7 在 Cursor 中得分 91.1%，高于 Claude Code 的 87.2%。Harness 决定发送的上下文与缓存策略，智能缓存可节省 40-80% 成本并提速 13-31%。
