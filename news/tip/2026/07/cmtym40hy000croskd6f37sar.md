# Cognition 实测：Fable 5 领衔的 Devin 成本反而低于 Opus 4.8

Cognition 用 FrontierCode 1.1 上的 3000 次评测对比 Fable 5 与 Opus 4.8，发现尽管 Fable 5 每 token 单价是 Opus 的 2 倍，在 Fusion 侧搭子架构下 Fable + Sidekick 每次运行成本 $1.86、得分 60.7，低于 Opus + Sidekick 的 $2.04 与 54.6。
