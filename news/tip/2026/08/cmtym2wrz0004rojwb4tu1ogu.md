# Tessl 实测：token 单价便宜不等于智能体任务成本低

Tessl 在为 Code Review 工具选模型时发现，按费率卡比较 token 单价会得出错误结论：三种更便宜的开源权重模型中有三种在真实 PR 审查中实际花费更高，一个模型每 token 便宜近 3 倍却在同一 PR 上贵 2.8 倍。
