# Mistral 复盘用 AI Agent 将 40,000 行 Fortran 77 迁移到 C++ 的方法与教训

Mistral 帮助一家欧洲能源运营商将 40,000 行 Fortran 77 的油藏模拟器迁移到 C++，该代码库无测试套件且文档分散。团队先搭建数值一致性验证工具，用 Vibe CLI 生成调用树并派出百余个 Agent 补齐文档，最终采用由人类把关的 coder、tester、reviewer 结构化工作流逐模块迁移。
