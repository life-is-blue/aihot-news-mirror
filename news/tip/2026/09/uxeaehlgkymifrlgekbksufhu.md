# Gemini 3.8 TTS 支持录制 20 秒复刻个人语音或用提示词设计自定义语音

Philipp Schmid 介绍 Gemini 3.8 TTS 支持通过录制 20 秒语音加同意句复刻个人声音，或用提示词设计完全自定义的语音。通过 API 调用创建后可在任意请求中使用，风格通过 speech_metadata 设置，作者还提供了博客链接和一段可交给智能体的完整操作提示词。
