# GitHub 安全团队如何用开源 AI 安全 Agent 找出 24 个 Android 漏洞

GitHub Security Lab 发布开源 seclab-taskflows 任务流，通过 gather_mobile_entry_point_info.yaml 和 classify_application_local.yaml 等提示词引导 LLM 审计 Android 应用，已发现并报告 24 个漏洞。
