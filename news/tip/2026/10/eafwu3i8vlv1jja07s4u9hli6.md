# Claude Code 中可将 Haiku 5.5 的 autocompact 窗口设为 100K 以留在更低定价档

Lydia Hallie 介绍 API 计费用户可将 Haiku 5.5 的 autocompact 窗口设为 100K，以保持在更便宜的 token 定价档。该设置按模型保存，仅适用于 Haiku 包括 subagents，命令为 /model haiku 和 /autocompact 100k。引用的 @ClaudeDevs 价格信息显示，100K tokens 以下为每百万 $0.10/$0.50（缓存读取 $0.01），以上为 $0.50/$2.50（缓存读取 $0.05）。
