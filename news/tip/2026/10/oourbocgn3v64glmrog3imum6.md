# Addy Osmani 谈让 Claude Code 自验证产出：代码审查需演进为多层验证体系

Addy Osmani 分享 Anthropic 团队的代码审查经验，指出给智能体提供验证手段可显著提升产出质量，Claude Code 已能自己写 90% 以上的代码。他认为当生成速度超过人工审阅能力时，逐行人工审查不再可行，应转向由 e2e 测试、property 测试和多智能体对抗式审查构成的多层验证体系，人聚焦产品意图、风险评估和证据评估，并按风险分级审批。
