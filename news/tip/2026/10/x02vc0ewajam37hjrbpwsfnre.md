# Claude Code 团队如何做代码审查：六层检查与风险分级审批

Anthropic Claude Code 团队详解在 Claude 写约 90% 代码的情况下如何组织代码审查：审查从终点关卡变为持续进行，每个 PR 经过验证、必需 CI、AI 审查、安全审查、按风险分级的人工审批和合并队列六层检查，再辅以快速回滚。
